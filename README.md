## 🌟 核心功能亮點

### 1. ⏰ 實時數字時鐘與早中晚心情籤語
- **大字體即時時鐘**：提供清晰流暢的 12 小時制時間顯示，中央配有隨律動跳動的粉紅愛心冒號 ♥。
- **動態心情籤語**：系統依據當前時間自動切換問候：
  - `05:00 - 09:00` 🌅 早安晨光！迎著微風開始美好的一天吧～
  - `09:00 - 12:00` ☀️ 元氣上午！記得喝杯溫水，保持滿滿專注力喔 ✨
  - `12:00 - 14:00` 🍱 午餐時間到！好好享用美食，補充能量再出發 🍙
  - `14:00 - 17:00` 🍰 悠閒下午茶！吃塊小餅乾，給自己一個大大的抱抱 🧁
  - `17:00 - 19:00` 🌇 傍晚夕陽好美！今天的你也超級棒，辛苦囉 🌸
  - `19:00 - 22:00` 🌙 美好晚間時光！聽首喜歡的歌，放鬆身心休息吧 🎵
  - `22:00 - 05:00` ⭐ 深夜靜悄悄～小動物都在睡覺囉，要早點休息祝好夢 💤

### 2. 📋 主頁「今日待辦」即時看板
- **主頁專屬展示區**：位於首頁核心卡片中央，無須翻頁即可掌握今日任務。
- **雙向即時同步**：
  - 可直接在主頁輸入框填寫任務並按 `Enter` 快速新增。
  - 亦可點擊「📖 手帳」展開完整筆記本管理。兩處資料 **100% 即時同步**。
- **完成度徽章**：動態計算當前進度（如 `0 件小事`、`1/2 完成`），打勾時伴隨甜蜜愛心飄出動畫。
- **直覺操作**：點擊方框即時打勾標記完成，滑鼠懸停可點擊 `✕` 刪除事項。

### 3. 📔 可愛元氣記事手帳本 (Notebook Modal)
- **活頁手帳擬態設計**：精緻的活頁鋼圈孔、信封襯線橫格筆記紙。
- **今日心情標籤**：可選擇並記錄今日好心情（🥰 開心、🌸 悠閒、🍰 甜蜜、⚡ 活力、💤 睏睏）。
- **雙分頁管理**：
  - 📝 **心情隨手記**：自由記錄心情點滴，具備自動保存（Auto-save）與手動保存機制。
  - 📋 **今日小願望待辦**：完整的待辦事項清單管理。
- **LocalStorage 本地持久化儲存**：重新整理或關閉瀏覽器，心情、隨手記與代辦清單皆完整保留。

### 4. 🐾 草坡萌寵漫步樂園（三隻小夥伴）
樂園中漫步著三隻由純 SVG 手工繪製的可愛小夥伴：
- 🐑 **軟萌小羊**：蓬鬆雲朵般的羊毛、下垂萌萌耳、粉紅項圈與黃金小鈴鐺。
  - 專屬台詞：「咩～ 🐑」、「毛茸茸的好暖和～ ☁️」、「嚼嚼青草真香甜 🌱」
- 🐱 **元氣小貓咪**：俏皮貓耳、擺動長尾巴、臉頰白斑與額頭小虎斑。
  - 專屬台詞：「喵嗚~ 🐾」、「呼嚕呼嚕 🥰」、「最喜歡小魚乾了！🐟」
- 🐰 **雪白小兔子**：柔軟長長垂耳、毛球尾巴、頭戴粉紫小花花。
  - 專屬台詞：「蹦蹦跳！🐰」、「想要胡蘿蔔 🥕」、「摸摸耳朵好舒服～ 💕」

**小夥伴趣味互動**：
- **摸摸拍拍**：點擊小動物會開心地跳躍起來、飄出愛心並彈出對話氣泡。
- **餵食點心**：點擊「餵食點心」按鈕或直接點擊草坡任意位置，會掉落草莓、餅乾、魚乾等點心，小動物會興奮地跑過去大快朵頤！
- **召喚萌寵**：點擊操作列「召喚萌寵」，隨機召喚新的可愛小夥伴一同玩耍。

### 5. 🌤️ 三大夢幻日夜氛圍切換
點擊「日光白晝」按鈕，可在三種不同情境中一鍵切換，背景、太陽月亮、浮雲、草坡及卡片色系同步變色：
1. **☀️ 日光白晝**：天藍與淡粉漸層、閃爍晨光、棉花糖白雲。
2. **🌅 夢幻晚霞**：紫紅與暖橘夕陽、濃郁霞光。
3. **🌙 星空黑夜**：深邃紫藍星空、銀月與隕石坑微光。

### 6. 🔔 Web Audio API 可愛純代碼合成音效
- 不需依賴外部 MP3 音訊檔，透過現代 Web Audio API 原生振盪器（Oscillator）即時合成：
  - 氣泡彈跳聲（Pop）
  - 撫摸小動物和弦音（Pet Melody）
  - 餵食嚼嚼聲（Munch）
  - 夢幻風鈴琶音（Chimes）
- 支援一鍵開啟 / 關閉音效。

### 7. 🌸 浪漫粒子畫布特效
- 點擊「撒花愛心」按鈕，觸發全螢幕 Canvas 粒子雨，漫天飛舞的花瓣、愛心、閃爍星星與旋轉小花，視覺效果驚豔！

### 8. 🎮 萌寵接甜點大冒險小遊戲 (Mini Game)
- **畫面位置**：精緻小遊戲卡片直接座落於主頁卡片**下方**，亦可點擊底部 Dock 的「🎮 玩小遊戲」按鈕一鍵滑順捲動前往！
- **出戰角色隨心切換**：
  - 🐑 **軟萌小羊**（最愛嫩草 🌱，吃到享專屬高分！）
  - 🐱 **元氣小貓咪**（最愛小魚乾 🐟，吃到享專屬高分！）
  - 🐰 **雪白小兔子**（最愛胡蘿蔔 🥕，吃到享專屬高分！）
- **豐富掉落機制**：
  - 草莓 🍓、餅乾 🍪、蛋糕 🍰、幸運星 ⭐（享額外加分與星光微粒）
  - 避開雷雨烏雲 ⛈️！一旦碰到會扣除 1 顆愛心 ❤️，共 3 次機會。
- **即時數據與排行榜**：
  - 即時統計得分、連擊數（Combo）、剩餘愛心。
  - 自動記錄個人最高分（LocalStorage 本地儲存），破紀錄時伴隨漫天花雨！
  - 結算稱號系統（👑 傳奇甜點守護神、🥇 甜點吃貨大師、🥈 貪吃小行家、🥉 甜點實習生）。
- **全平台多種操控**：
  - 電腦端：支援鍵盤 `← / →` 或 `A / D` 鍵、滑鼠在畫布上自由滑動。
  - 行動端：支援觸控直接在畫布上拖曳，或使用畫面下方的虛擬左右按鈕！

## 🛠️ 技術架構
- **結構**：HTML5 語義化標籤
- **樣式**：Vanilla CSS3（純原生 CSS，採用 CSS Variables、Flexbox、Grid、Glassmorphism 毛玻璃特效、Keyframe 動畫）
- **字型**：Google Fonts (`Zen Maru Gothic` 日系圓體、`Nunito` 活潑英文字體)
- **邏輯**：Modern JavaScript (ES6+)
- **音訊引擎**：HTML5 Web Audio API (OscillatorNode, GainNode)
- **動畫特效**：HTML5 Canvas 2D Context & RequestAnimationFrame
- **資料儲存**：Browser LocalStorage API

## 🚀 如何執行與預覽

### 🌐 線上展示 (Live Demo)
直接點擊此連結即可立即線上體驗：  
👉 **[https://fishlovewater.github.io/0916HW/](https://fishlovewater.github.io/0916HW/)**

### 方法一：直接於瀏覽器開啟（本地最簡便）
本專案為純前端靜態架構，無須安裝複雜的後端環境或套件：
1. 下載或進入本專案資料夾 `0916HW`。
2. 對著 `index.html` 點擊滑鼠右鍵，選擇以任何主流瀏覽器（Google Chrome、Microsoft Edge、Safari 等）開啟即可。

### 方法二：使用本地輕量伺服器
若習慣在本地伺服器環境預覽：
```bash
# 使用 VSCode 的 Live Server 套件直接開啟
# 或使用 Python 內建伺服器：
python -m http.server 8080

# 或使用 Node.js serve：
npx serve .
```
開啟瀏覽器訪問 `http://localhost:8080` 即可暢快體驗！
